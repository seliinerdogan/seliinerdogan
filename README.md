**[Predicting Generalization Failures in Financial Vulnerability Models Across Countries](https://github.com/seliinerdogan/financial-vulnerability-generalization)**

An independent research project using World Bank Global Findex 2025 data to evaluate how reliably machine learning models generalize across 98 countries.

I compare four algorithms, investigate distribution shift and calibration, and examine whether country-level model performance can be anticipated before observing outcomes.
